Excel / CSV Import & Export

Export contacts to CSV, which opens in Excel. Excel .xlsx import/export uses the SheetJS library and needs an internet connection when that library is not already loaded.

Import matches columns by header name. Existing contacts are not automatically deleted. Review duplicates after importing.

Local Backup & Restore

Contacts are stored in this browser on this device. Make regular backups. Browser data clearing, device loss or switching browsers can remove access to local contacts.

Age Group Reference

Age is calculated from date of birth using today's date. Groups use five-year ranges: 0–4, 5–9, 10–14, 15–19, 20–24, 25–29, 30–34, 35–39, 40–44, 45–49, and so on.

This is a single-user local app. Cloud sync and multi-user login are intentionally not enabled in this phase.
